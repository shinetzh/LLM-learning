1

RoPE：用旋转把位置信息注入 Q、K

核心想法：同一内容放在不同位置时，按位置旋转；不同维度对使用不同频率。

1.1 为什么是旋转？

把每两个通道视为二维向量。位置 m 决定旋转角度，旋转后的向量模长不变，但方向随位置变化。

x′m,i = R(m θi) xi
R(φ) =cos φ−sin φsin φcos φ

固定维度对 i，改变位置 m

角度随位置线性增加：φm,i = m θi。同一个 feature 在位置 0、1、2… 会转到不同方向。

固定位置 m，改变维度对 i

每对维度有不同 θi，所以同一个 token 内，不同维度对旋转快慢不同。

1.2 不同 index 为什么有不同频率？

θi = base−2i/d　（常见 base = 10000）
φm,i = m · θi

i 是“二维通道对”的索引（0 到 d/2−1），不是单个通道编号。i 越大，频率越低。多频率让模型能同时拥有较细的局部位置分辨率和较慢变化的长距离位置尺度。

维度对频率 θ（示例 d=8）在位置 m=100 的累计角度直觉
(0,1), i=01100 rad ≈ 5729.6°高频、短周期，角度变化快
(2,3), i=10.110 rad ≈ 573.0°中高频
(4,5), i=20.011 rad ≈ 57.3°中低频
(6,7), i=30.0010.1 rad ≈ 5.7°低频、长周期，角度变化慢
关键澄清：不是“越靠后的位置角度越小”。固定 i 时，位置 m 越大，累计角度 mθi 越大；固定 m 时，维度对索引 i 越大，频率越低、累计角度通常越小。

1.3 交互观察：位置与维度对如何决定角度

四个单位圆共用同一个位置 m。虚线是 m = 0 的初始方向，实线是当前方向；每次 m 增加 1，转角增加 θi。圆上的方向只显示累计角度对 360° 取模后的结果，下方圈数保留完整旋转信息。

i=0（最高频）i≈d/6i≈d/3i=d/2−1（最低频）

这里用初始向量 (1, 0) 演示旋转：当前方向为 (cos(mθᵢ), sin(mθᵢ))。相位会周期性重复，但累计角度和圈数不会丢失；播放时四个 index 都按同一速度推进 m，不单独加速低频维度。低频方向在相邻位置几乎不动，正是频率更低的表现。

1.4 为什么 Attention 能感知相对位置？

q′mT k′n = qT R((n−m)θ) k

Q、K 分别按各自位置旋转后，它们的点积包含相对位置差 n−m。这让 Attention 的匹配同时受内容特征与相对位置影响。注意：真实 q 与 k 通常不同，上式不是简单的“距离越近相似度必然越高”。

2

长上下文需求：为什么原始 RoPE 需要调整？

训练长度之外的位置属于外推；直接拉长序列，并不能保证模型仍能稳定利用位置。

问题 A

位置范围超出训练分布

如果模型训练时只见过长度 L，推理时突然使用更大的位置，模型可能遇到未充分训练过的相位组合。

问题 B

简单统一缩放有副作用

位置插值 PI 把所有位置变成 m/s，相当于所有 RoPE 频率都除以 s。长上下文变得可表示，但高频维度的局部位置变化也被压慢。

PI：　m′ = m / s　　⇒　　θ′i = θi / s

其中 L 是原始训练上下文长度，目标长度约为 sL。统一缩放对所有维度一视同仁，没有充分利用不同频率负责不同位置尺度这一结构。

3

YaRN：分频段插值，兼顾局部与长距离

第一步改频率：低频更多插值，高频尽量保留，中间平滑过渡。

3.1 为什么要分段？

不同频率维度的波长不同，因此它们对“扩展位置范围”的需求不同。低频本来旋转慢，适合承担更长尺度；高频有助于保留局部区分能力，不宜全部按相同比例压慢。

低频区

更多插值

θ′ = θ / s

扩大有效位置范围。

过渡区

平滑混合

θ′ = ((1−γ)/s + γ) θ

避免频段边界突变。

高频区

保留原频率

θ′ = θ

尽可能保留局部位置分辨率。

3.2 分段方法的核心公式

θ′i = [ (1−γi)/s + γi ] θi

γi 是由该维度波长/旋转次数与阈值决定的 0 到 1 的平滑 ramp：

γ(r) = 0　（低频区）
γ(r) = (r−α)/(β−α)　（过渡区）
γ(r) = 1　（高频区）

直觉上：γ=0 时完全按 PI 缩放；γ=1 时保持原频率；中间值则在两者之间插值。具体阈值和维度索引映射应采用目标模型/框架的 YaRN 配置，不同实现的参数约定可能略有差异。

为什么还要配合 Attention Scaling？

频率调整与 logits 尺度校准解决的是两个相关但不同的问题。

4.1 Softmax 对 logits 的尺度敏感

Attention = softmax(QKT / √dk)

如果 logits 的差异变大，Softmax 通常更尖锐；差异变小，分布通常更平。排序可能不变，但权重分配会明显变化。

交互示例使用 logits = [1, 2, 3]，只用于说明 Softmax 的尺度敏感性，不是某个模型的实测 Attention。

4.2 YaRN 的 Attention Scaling 做法

c(s) = 1 + 0.1 ln(s)
Q′ = cQ，K′ = cK　⇒　Q′K′T = c² QKT

YaRN 的常见实现将旋转后的 Q、K 同时乘以 c，相当于把 Attention logits 乘以 c²。该缩放系数是论文针对相应模型设置给出的经验校准规律，不是对所有架构都必然最优的定理。

扩展倍数 sc = 1 + 0.1 ln(s)logits 倍数 c²直觉
2×1.0691.143×轻微校准
4×1.1391.297×适度校准
8×1.2081.460×更明显校准
16×1.2771.630×更明显校准
重要细节：Attention Scaling 不会恢复已经丢失的位置信息，也不等于直接增加上下文长度。它用于校准注意力数值尺度；分频段频率调整则改变位置相位的变化方式。
5

把整条逻辑串起来

YaRN 不是单独一个缩放公式，而是位置频率设计与 Attention 数值校准的组合。

Step 1 · RoPE不同频率旋转

位置 m 通过角度 mθi 进入 Q、K；多频率提供多尺度的位置线索。

Step 2 · 长上下文扩展位置范围

直接外推不稳；统一插值会把所有频率都压慢，可能损害局部位置分辨率。

Step 3 · YaRN分频段 + 校准

低频更多插值、高频尽量保留；再通过 Attention Scaling 校准 logits 的尺度。

一句话总结：RoPE 用不同频率的旋转表达位置；YaRN 在扩展上下文时，按频段决定“哪些旋转要变慢、哪些尽量保持”，并用 Attention Scaling 校准注意力分布的尺度。实际效果仍取决于模型架构、训练配置和微调数据。
